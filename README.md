# Iris Flower Classification using Machine Learning
Machine Learning project for Iris flower species classification using KNN, Logistic Regression, and Naive Bayes.

This project classifies Iris flower species using machine learning algorithms based on flower measurements.

## Dataset Features
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## Target Classes
- Iris-setosa
- Iris-versicolor
- Iris-virginica

## Algorithms Used
- K-Nearest Neighbors (KNN)
- Logistic Regression
- Naive Bayes

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Workflow
1. Data Loading
2. Data Preprocessing
3. Feature Scaling
4. Train-Test Split
5. Model Training
6. Model Evaluation
7. Accuracy Comparison

## Conclusion
Among all models, KNN achieved the best performance for Iris flower classification.
